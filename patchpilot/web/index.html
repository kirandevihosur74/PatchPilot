The problem

Security backlogs are 90% noise.

Scanners match version strings — "you have PyYAML 5.3.1, it's in the vulnerable range." They can't tell whether the vulnerable path is reachable in your code, so teams drown in alerts and patch nothing while real CVEs sit for months.

How it works

Isolate. Generate. Evaluate. Review.

One loop, wired end to end across four systems — each one load-bearing, none decorative.

01 · Isolate
Daytona
Sandboxes

Every exploit and patch attempt runs in a throwaway sandbox. Running a live RCE on stage is safe because it never touches a real machine.

02 · Generate
Fireworks
Two-model loop

A fast model triages the breakage; a coder model writes the fix — self-correcting until the suite is green.

03 · Evaluate
Braintrust
Traces + eval

Every step is traced and scored. A security eval fails any fix that weakens the code to pass the tests.

04 · Review
CodeRabbit
Independent gate

An independent AI reviews the patch PR. Merge gates on tests and review both. The agent that writes the patch never approves it.
